# Localrepo

A hands-on Git and GitHub practice repository demonstrating version control workflows.

## 📌 Features & Demonstrations
- **Branch Management:** Creating and managing feature branches (dropdowns, UI buttons).
- **Commit History & Merges:** Working with git staging, commit conventions, and merge workflows.
- **Frontend Components:** Basic HTML/CSS interactive elements.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/AyushShah1107/Localrepo.git
   ```
2. Open `index.html` in any web browser.
